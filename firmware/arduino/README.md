# Arduino firmware

Joshua-owned `joshua_wire_v1` firmware for Arduino-family boards.

| Image | MCU | Host `BoardType` | Status |
| --- | --- | --- | --- |
| [`uno/`](uno/README.md) | ATmega328P (Uno R3) | `ARDUINO_UNO` | Source in tree; not yet flashed on hardware |

Follow [`uno/README.md`](uno/README.md) for build, flash, and wiring.
The host class is `robot/board/arduino/arduino_board.h`.
